- [ ] 2.5 Колонка без ответа: перебор вернул пусто — колонка остаётся и несёт причину («не

## 3. Интерфейс

- [ ] 3.1 Колонка отметок в таблице выдачи: отметка адресует пару «локомотив + число секций»,
      не меняет ни состав выдачи, ни порядок, ни числа; предел — четыре машины, при попытке
      отметить пятую видно почему; проверка — тест вкладки в `features/optimizer/__tests__/`
      (файл на русском, как соседи)
- [ ] 3.2 Команда «Сравнить» и панель над таблицей: показатели строками, машины колонками с
      картинкой и названием, подпись про общий вагон; команда доступна от двух отмеченных, при
      одной — подсказка, что нужна ещё машина; проверка — тест вкладки на оба состояния
- [ ] 3.3 Сброс отметок и закрытие панели при смене задачи — по всему набору зависимостей, от
      которых пересчитывается выдача (груз, год, плечо, станция, выпуск, предел поездов,
      получатель, исключённые машины, тип пути, настройки), но НЕ при смене цели; проверка —
      тест вкладки: смена груза снимает отметки, переключение цели их сохраняет
- [ ] 3.4 Строки интерфейса в `web/src/i18n/en.json` и `ru.json` (заголовок панели, подписи
      показателей, подсказка про предел и про вторую машину, подпись общего вагона); проверка —
      `cd web && npx vitest run locales`
