## 2. Сравнение как данные

- [x] 2.1 Чистая функция сравнения в `features/optimizer/comparison.ts`: принимает отмеченные
      пары «локомотив + число секций», параметры исходного поиска, список машин и кэш,
      возвращает по колонке на пару (через `searchConsists` с `trains = [engine, wagon]`,
      вагон — из первой отмеченной строки, из ответа берётся строка с отмеченной
      секционностью); проверка — тесты «у всех колонок один и тот же вагон», «длина состава не
      больше станции», «отмечена двухсекционная строка → в колонке две секции»
- [x] 2.5 Колонка без ответа: перебор вернул пусто — колонка остаётся и несёт причину («не
      подходит» либо, когда цель отвергла всё, её условия из `refused`); проверка — тесты на
      оба случая (тяжёлый вагон под слабой машиной; цель «Мин. расходы» с недостижимой задачей)
- [x] 2.6 Тесты «парк подобран заново под общим вагоном» и «переключение цели меняет числа
      панели так же, как выдачу»; проверка — оба теста зелёные
- [x] 2.2 Раскладка показателей: список строк панели со значением, форматом, направлением
      «лучше» и признаком «нет значения»; проверка — тест «показатели идут в объявленном
      порядке, строка окна поставок отсутствует без вердикта получателя»
- [x] 2.3 Лучшее значение: по каждой строке отметить лучшее с учётом направления показателя;
      ничья отмечает всех; показатель без значения не участвует, а у описательных строк
      (длина, вагоны, парк) лучшего не бывает вовсе. Отставание в процентах не считаем — оно
      в Non-goals; проверка — тесты «отмечают лучшее с учётом направления», «при ничьей
      отмечают всех», «не отмечают лучшим того, у кого значения нет»
- [x] 2.4 Тест «числа сравнения совпадают со строкой выдачи», когда у машины в таблице уже
      стоял общий вагон и то же число вагонов; проверка — сравнение полей строки и колонки

## 3. Интерфейс

- [x] 3.1 Колонка отметок в таблице выдачи: отметка адресует пару «локомотив + число секций»,
      не меняет ни состав выдачи, ни порядок, ни числа; предел — четыре машины, при попытке
      отметить пятую видно почему; проверка — тест вкладки в `features/optimizer/__tests__/`
      (файл на русском, как соседи)
- [x] 3.2 Команда «Сравнить» и панель над таблицей: показатели строками, машины колонками с
      картинкой и названием, подпись про общий вагон; команда доступна от двух отмеченных, при
      одной — подсказка, что нужна ещё машина; проверка — тест вкладки на оба состояния
- [x] 3.3 Сброс отметок и закрытие панели при смене задачи — по всему набору зависимостей, от
      которых пересчитывается выдача (груз, год, плечо, станция, выпуск, предел поездов,
      получатель, исключённые машины, тип пути, настройки), но НЕ при смене цели; проверка —
      тест вкладки: смена груза снимает отметки, переключение цели их сохраняет
- [x] 3.4 Строки интерфейса в `web/src/i18n/en.json` и `ru.json` (заголовок панели, подписи
      показателей, подсказка про предел и про вторую машину, подпись общего вагона); проверка —
      `cd web && npx vitest run locales`
