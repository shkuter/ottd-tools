- [x] 6.1 Секция `named` в палитре (`TC_*`, `PC_*`) плюс починка разбора `enum Colours` под
      пин OpenTTD 15.3 — без них цвета ролей взять неоткуда
- [x] 6.2 Единое начертание: у шрифта игры одна гарнитура, жирный синтезируется браузером

      получает, чёрный и приглушённый — нет
- [x] 6.4 Выбранный пункт списка адресуется атрибутом `data-combobox-option` + `data-checked`:

      клавиатурный курсор, а не выбор, — правило не срабатывало ни на выбранном, ни на
      наведённом
- [x] 6.5 Штриховка недоступного добирает вкладки, флажки и переключатели-радио

- [x] 6.7 Цветовые группы окна — один список (`WINDOW_COLOURS` в `skin.ts`), тест сверяет его

- [x] 6.8 Кегль заголовка — токен `--skin-font-heading` вместо четырёх копий выражения;
      неиспользуемые токены метрик удалены
