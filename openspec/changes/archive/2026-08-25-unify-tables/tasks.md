## 7. Правки по ревью

- [x] 7.1 Каталог: не хранить `null` как «порядок по умолчанию» — состояние заводится значением
      `DEFAULT_SORT`, а третий щелчок приводит к нему же (`setSort(next ?? DEFAULT_SORT)`).
      Проверка: список отсортирован по году **и** колонка «Год» помечена стрелкой; первый
      щелчок по ней разворачивает порядок, а не просто рисует значок.
- [x] 7.2 Карта оптимизатора: `rating` отдаёт `null` вместо `-1`, когда рейтинга нет, — ячейка
      в этом случае рисует «—». Проверка: кейс в `components/table/__tests__/sorting.test.ts`
      по образцу `supply` и `payback` — такие строки в конце при обоих направлениях.
- [~] 7.3 ~~Карта оптимизатора объявляется через union колонок, а не
      `satisfies SortValues<OptimizeResult, string>`.~~ **Снята: посылка неверна.** Проверено
      пробником на `tsc` этого проекта — `satisfies` не расширяет объект, `keyof typeof` в обоих
      случаях даёт union литеральных ключей, и заголовок не может сослаться на колонку, которой
      в карте нет. Снятие `satisfies` только убрало бы проверку того, что записи карты
      возвращают `number | string | null`.
- [x] 7.4 `TableFrame` принимает `rowCount` и `emptyMessage` и сам решает, пуст ли список;
      пропы `className` и `tableClassName` убрать вместе с классом `supply-inputs`, у которого
      нет правил CSS. Три страницы перевести на новый вызов.
- [x] 7.5 Каталог: спрайт и название — одна ячейка под сортируемым заголовком «Название»,
      чтобы пин удерживал то, по чему строка узнаётся. Правило просвета сузить до
      `:has(> .train-sprite:only-child)`, иначе ячейка с текстом получит `line-height: 0`.
      Проверка в браузере: при прокрутке вбок видно название строки.
- [x] 7.6 Перенести наши классы (`.table-wrap`, `.pin-edges`, `.sort-mark`, `.table-empty`) из
      `skin-mantine.css` в `skin.css`, к уже описанному там `.table-wrap`; в `skin-mantine.css`
      оставить `.mantine-*`. Заодно `.sortable:hover` перевести на `--skin-list-hover`.
- [x] 7.7 Прогнать `make verify` и убедиться, что визуальный кейс таблиц по-прежнему проходит
      (пин каталога теперь измеряет ячейку со спрайтом и названием).
