## 1. Чтение карты

- [x] 1.1 Чанки карты в `WANTED_CHUNKS` (`web/src/savegame/parse.ts`): `WMAP` и ванильные
      `MAPT`, `MAPH`, `MAPO`, `MAP2`, `M3LO`, `M3HI`, `MAP5`, `MAPE`, `MAP7`, `MAP8`, плюс
      `RAIL` и `ROTT`. Сверх задачи понадобились три чанка: `MAPH` — высота нужна, чтобы
      тоннель нашёл свой второй конец так же, как его ищет игра (`GetTileZ`, а не байт
      `height`); `MAP2` — в нём JGRPP держит дорожные биты кастомного торца моста; `RAIL` и
      `ROTT` — без лейблов индекс типа путей в тайле не значит ничего, а блок обслуживания
      ключуется лейблом. На обеих фикстурах чанки приходят непустыми (`WMAP` = size × 12)
- [x] 1.2 Написать `web/src/savegame/extract/tiles.ts`: читалки полей тайла по индексу
      (`type`, `m1`, `m3`, `m4`, `m5`, `m6`, `m7`, `m8`) поверх байтов чанка, без копий.
      Ветка `WMAP` — два массива подряд (`size × 8` байт `Tile`, затем `size × 4` байта
      `TileExtended`), ветка ванили — по массиву на поле; тест: обе ветки дают одни и те же
      значения на одних и тех же тайлах
- [x] 1.3 Ветка «карта не разобрана»: `WMAP` длиной `size × 10` (расширение по 2 байта, нет
      `m8`), отсутствие чанков, длина, не сходящаяся с размером из `MAPS`; тест: читалка
      возвращает «не смогли», а не бросает и не отдаёт мусор

## 3. Снапшот

- [x] 3.1 Счётчики в снапшоте необязательным полем на компанию (`snapshot.ts`); собираются в
      воркере — правки `worker.ts` не потребовалось, он и так зовёт `readSavegame`. Ассерт,
      что тайлы в снапшот не попадают, — по размеру сериализованного снапшота фикстуры
- [x] 3.2 Версия схемы снапшота поднята до 5. Тест на сброс снапшота прошлой версии уже
      есть и написан относительно версии (`snapshotStore.test.ts`: запись со
      `SNAPSHOT_SCHEMA_VERSION - 1` отбрасывается и `droppedOutdated` становится true), так
      что бампом он покрыт — дублировать не стал
- [x] 3.3 Сверка с партией: счётчики совпали с окном инфраструктуры **до единицы** на обеих
      фикстурах. Поправка к формулировке задачи: `vanilla-1951.sav` — тоже сохранение
      патчпака и лежит в `WMAP` (1 572 864 = 131 072 × 12), ванильной ветки раздельных чанков
      среди фикстур нет вовсе; она проверяется синтетической картой, собранной обеими
      раскладками из одних и тех же тайлов
- [x] 3.4 Замер: подсчёт по карте 512×512 (262 144 тайла) `londworth-1975` — **0,7 мс**
      (лучшее из семи прогонов), то есть около **50 мс** на 16,7 млн тайлов. В секунду-две
      укладывается с запасом, раскладку чтения менять не пришлось. Разбор всего файла
      целиком — 75 мс, и это почти целиком распаковка, которая шла и раньше: массивы карты
      живут подвидами поверх уже распакованного буфера, копий нет
