## Why

Импорт сейва сегодня достаёт только настройки (`PATS`, `NGRF`, `ECMY`, `DATE`) — сама сеть
игрока (поезда, приказы, станции, индустрии) остаётся в файле. Чтобы калькулятор мог показать
партию и подставлять реальные составы и маршруты в расчёты (вкладка «Партия» и мосты в
Route income / оптимизатор — следующие изменения серии), нужен полный разбор сейва и
хранимый снапшот. Это изменение закладывает слой данных; UI поверх него — отдельно.

## What Changes

- Пайплайн экспортирует `numeric_id` машин Iron Horse в `trains.json` (и внутренние id
  ванильных машин) — без них поезд из сейва не сопоставить каталогу: сейв ссылается на
  машины через пул движков (GRFID + внутренний id).
- Парсер сейва читает сеть партии: машины и составы, приказы (включая общие), станции с
  ожидающим грузом и рейтингами, индустрии, города, группы, компании и служебные таблицы
  для сопоставления машин и подсчёта груза — для JGRPP и ванили. Список чанков — в
  design.md.
- Из прочитанного собирается **снапшот партии**: маршруты (= общие приказы + их поезда),
  поезда с составами, станции, индустрии, по компаниям. Один снапшот, хранится в IndexedDB
  с версией схемы; устаревшая версия просит загрузить файл заново, а не читается вслепую.
- Имена городов: порт генератора English Original (имя города в сейве — сид, не строка);
  суффиксы станций извлекаются из lang-файлов игры (`STR_SV_STNAME_*`) и из строк FIRS
  (станции, названные по индустрии: «Печь») и следуют языку калькулятора, как в самой игре. Прочие стили имён — заглушка «Город #N».
  Переименованные вручную города/станции приходят строками и показываются как есть.
- Единый флоу импорта: один файл даёт и настройки (существующее поведение), и снапшот —
  одним подтверждением.

## Capabilities

### New Capabilities

- `savegame-snapshot`: что калькулятор извлекает из сейва сверх настроек — маршруты, поезда,
  станции, индустрии, города, группы, компании; как машины сейва сопоставляются каталогу;
  как генерируются имена; как снапшот хранится и версионируется.

### Modified Capabilities

- `savegame-import`: импорт одного файла теперь даёт настройки **и** снапшот партии одним
  подтверждением; панель импорта сообщает о собранном снапшоте.

## Impact

- `pipeline/extract_iron_horse.py`, `extract_vanilla.py` → `trains.json`, `vanilla.json`
  (+ `validate.py`, эталоны в `pipeline/tests/`): поле `numeric_id` / внутренний id.
- `web/src/savegame/`: новые экстракторы чанков (`extract/*`), сборка снапшота, хранилище
  IndexedDB, расширение `read.ts` / `parse.ts` / `import.ts` / `apply.ts`.
- Новый модуль генерации имён городов + извлечение суффиксов станций в словари i18n
  (`pipeline/extract_firs_ru.py` или соседний экстрактор, `make check-i18n`).
- `SavegameImportPanel.tsx` — упоминание снапшота в подтверждении.
- Источники истины: `vendor/openttd/src/saveload/{vehicle,station,industry,town,order,group,company}_sl.cpp`,
  `vendor/openttd/src/townname.cpp` + `table/townname.h`, lang-файлы
  (`russian.txt`/`english.txt`); JGRPP-раскладки — `vendor/openttd-patches/src/saveload/`;
  `numeric_id` — исходники Iron Horse в `vendor/iron-horse`.
- Semver: **minor** (новая функциональность и набор данных; числа расчётов при том же вводе
  не меняются, localStorage не сбрасывается — IndexedDB добавляется рядом).

## Non-goals

- Вкладка «Партия» и любой UI по снапшоту (change 2 серии).
- Мосты в Route income / оптимизатор, сверка «факт vs прогноз» (change 3).
- Сверка рейтинга станций с `engine/rating.ts`, финансы/графики, библиотека нескольких
  сейвов, стили имён городов кроме English Original.
