# Graphics attribution

All graphics shipped in this directory are derived from GPL-licensed OpenTTD content and
stay under those licences.

## OpenGFX2 Classic 0.8.1 — `icons/vanilla_trains/`, `icons/vanilla_cargo/`

Vehicle sprites and cargo icons of the vanilla (base game) mode are extracted from the
OpenGFX2 Classic base graphics set: <https://github.com/OpenTTD/OpenGFX2/>

Created by Zephyris (Richard Wheeler) with contributions from MasterOktagon, J-PIE-314,
SosMakaroni and the OpenGFX authors it derives from. Licensed under the **GNU General
Public License version 2 or later**, as stated in the set's own `opengfx2_8.obg`.

The GUI palette in `web/src/data/opengfx2_palette.json` comes from the same set (the
recolour sprites the game reads its window gradients from).

## OpenTTD — fonts and palette

`web/public/fonts/OpenTTD-*.ttf` are the game's own fonts from
<https://github.com/OpenTTD/OpenTTD-TTF>, GPL-2.0. The DOS palette used when decoding
sprites comes from OpenTTD itself (`src/table/palettes.h`), GPL-2.0.

## Iron Horse — `icons/trains/`

Vehicle sprites rendered from the Iron Horse train set by Andy (andythenorth):
<https://github.com/andythenorth/iron-horse>, GPL-2.0.

## FIRS — `icons/cargo/`, `icons/industries/`

Cargo icons and the industry pictures of the chain graph (the set's own documentation
artwork, `src/docs/static/img/industries/`) from FIRS Industry Replacement Set by Andy
(andythenorth): <https://github.com/andythenorth/firs>, GPL-2.0.
